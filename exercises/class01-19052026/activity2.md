Para cada necesidad (A, B, C), decide qué topología implementar: Internet, Intranet o Extranet. Justifica en 2 líneas cada una.

- (A) Internet: Esta debe ser publica y accesible desde cualquier lugar para que todos los vecinos logren consultar informacion y hagan tramites

- (B) Intranet: Esta maneja datos privados y sensibles de salarios de usuarios, lo correcto es que solo personal pueda consultar esto

- (C) Extranet: Permite a usuarios externos especificos accedan de forma segura a los datos mediante credenciales

¿Cuál de los tres sistemas requiere más inversión en seguridad? ¿Por qué?

- R: El sistema (B) porque maneja datos sensibles y fugas de estos pueden generar problemas legales.

¿Podría un mismo servidor físico alojar los tres sistemas de forma segura? ¿Cómo lo lograrías conceptualmente?

- R: Se puede lograr mediante contenedores y segmentacion de redes virtuales y firewalls para mantener el aislamiento.
