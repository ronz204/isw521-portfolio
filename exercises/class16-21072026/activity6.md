# Actividad #6 - Emparejando escenarios con Angular, React o Vue

### Emparejen cada escenario con Angular, React o Vue: (1) migrar poco a poco un sitio Laravel viejo sin reescribirlo entero, (2) app bancaria con 40 desarrolladores por 8 años, (3) equipo de 3 personas armando un MVP rápido con máxima libertad de herramientas.

- **R:**

**1. Migrar poco a poco un sitio Laravel viejo → Vue.** Vue está diseñado para adopción incremental: se puede montar en una sola vista o componente de una página existente sin necesidad de reescribir el resto del sitio ni tocar el backend. Es el caso de uso histórico por el que Vue se hizo popular.

**2. App bancaria con 40 desarrolladores por 8 años → Angular.** Mismo razonamiento que en la Actividad #4: equipo grande, alta necesidad de convención, horizonte largo. Angular impone estructura y trae todo integrado, lo que reduce la fragmentación de decisiones a lo largo de 8 años y varias generaciones de desarrolladores.

**3. Equipo de 3 personas armando un MVP rápido con máxima libertad de herramientas → React.** Un equipo chico no necesita la rigidez de un framework opinionado; se beneficia más de la flexibilidad de React y de su ecosistema enorme para elegir exactamente las piezas (router, estado, UI kit) que necesita para salir rápido con un MVP, sin cargar con convenciones que no le aportan valor a esa escala.
